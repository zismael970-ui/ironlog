# IRONLOG — Training Intelligence

Versión 2.1.3. Aplicación de registro de entrenamientos, perfiles locales, histórico y evolución.

## Publicar

Sube index.html y .nojekyll a la raíz. En Settings → Pages, elige Deploy from a branch, main y /(root), y pulsa Save.

## iPhone y iPad

Abre el enlace publicado con Safari. Puedes usar Compartir → Añadir a pantalla de inicio. No es necesario instalar la aplicación GitHub.

Cada navegador y dispositivo guarda sus datos por separado. No hay sincronización ni cuentas online. Exporta una copia JSON antes de trasladar tus datos y luego impórtala en la web. No subas copias personales al repositorio.

El archivo publicado utiliza un perfil inicial neutro; no incluye entrenamientos ni medidas personales. Se conservan las funciones de IRONLOG 2.1.3. Esta publicación no incorpora caché offline: abre la página con conexión.
